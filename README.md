# My Truck Loads

A mobile-friendly truck load log for tracking loads, mileage, extra pay, payment status, weekly pay history, and operating statistics.

## Features

- Add, edit, and delete load entries
- Track empty and loaded mileage
- Calculate mileage pay and extra income
- Mark loads as paid or unpaid
- Weekly pay history with Friday pay dates
- Historical load statistics
- Shipper, destination, and trailer charts
- Excel export
- JSON backup and restore
- Local browser storage
- Print-friendly view
- Sarcastic Swede red-and-black theme

## Use

Open `index.html` in a web browser. Data is stored locally in that browser using `localStorage`.

## Deployment

This is a static web app and can be deployed directly through Vercel with no build command. The output directory is the repository root.

## Important

Browser data does not automatically transfer between devices or browsers. Use **Backup Data** regularly and keep the downloaded JSON file somewhere safe.
